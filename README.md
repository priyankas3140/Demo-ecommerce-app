# Seora — E-commerce Storefront

A polished, responsive e-commerce storefront demo built with vanilla HTML, CSS, and JavaScript.

## Features

- Responsive catalogue for desktop and mobile
- Product search with live suggestions
- Category, price, and checkbox filters
- Product sorting and result counts
- Product detail views with size options, reviews, and shipping details
- Wishlist interactions and recommended products
- Persistent shopping bag powered by browser local storage
- Quantity controls, item removal, and promo code support (`WELCOME10`)
- Local checkout experience and account interface
- Newsletter, editorial, and customer-care sections

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

No installation or build process is required.

1. Clone this repository.
2. Open `index.html` in a web browser.

## Project structure

```text
├── index.html   # Storefront layout and UI
├── style.css    # Responsive styles and modal/cart UI
└── app.js       # Catalogue, search, filters, cart, checkout interactions
```

## Demo note

This is a frontend demonstration. Cart data is saved only in the current browser. Payments, account login, inventory, and order persistence would need a backend service and database for production use.
